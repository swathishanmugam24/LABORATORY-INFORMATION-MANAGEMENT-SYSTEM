 🔬 Laboratory Information Management System (LIMS)
 📌 About the Project

The **Laboratory Information Management System (LIMS)** is a Java-based desktop application developed to manage and organize day-to-day laboratory activities efficiently. It provides a centralized platform to handle laboratory inventory, sample registration, research results, equipment reservations, maintenance records, and user requests.

The main purpose of this project is to reduce manual paperwork, improve data accuracy, simplify laboratory operations, and maintain organized records. The system provides a user-friendly graphical interface developed using Java Swing.

 🎯 Key Features

- User Management:** Provides role-based access for Admin, Technician, and Researcher.
- Inventory Management:** Maintains laboratory equipment, chemicals, stock quantities, and storage locations.
- Sample Management:** Registers and tracks laboratory samples based on their status.
- Results Management:** Stores and manages sample analysis results and related information.
- Equipment Reservation:** Allows users to reserve laboratory equipment and checks scheduling conflicts.
- Maintenance Management:** Maintains equipment servicing and maintenance records.
- Request Management:** Supports submitting, approving, and rejecting laboratory requests.
- Reports and Logs:** Generates laboratory summaries and maintains activity records.
- Data Export:** Supports exporting records into CSV and HTML formats.

🛠️ Technologies Used

- Java
- Java Swing and AWT
- Java Serialization for local data storage
- SHA-256 password hashing
- Visual Studio Code

🎯 Project Objective

To develop a simple and efficient digital solution that improves laboratory workflow, simplifies information management, and provides organized access to laboratory records.

🔐 Three-Role Login System
The LIMS provides three types of role-based login:

- **Admin:Manages users, inventory, samples, and requests.
- **Technician:Handles inventory, samples, results, and maintenance.
- **Researcher:Submits requests, views results, and reserves equipment.

Each role has specific permissions, ensuring secure and efficient laboratory management.

📖 Conclusion

The Laboratory Information Management System helps laboratories manage their daily activities through a single application. It improves record organization, simplifies sample and inventory tracking, and supports efficient laboratory management.
